Uso
Descarga el archivo index.html
Ábrelo con doble clic en cualquier navegador
Presiona "Girar" para comenzar

No requiere instalación ni conexión a internet.

¿Qué hace?
Genera una ruleta con distintas problemáticas ambientales
Al detenerse, muestra un escenario
Propone posibles acciones frente a esa situación
El jugador debe escoger la respuesta correcta

Tecnologías
HTML
CSS
JavaScript (Canvas API)

Notas
Funciona completamente en el navegador
No usa librerías externas
Puede modificarse fácilmente agregando más opciones en el arreglo options dentro del código
