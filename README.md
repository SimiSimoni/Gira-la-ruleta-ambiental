Uso <br />
Descarga el archivo index.html <br />
Ábrelo con doble clic en cualquier navegador <br />
Presiona "Girar" para comenzar <br />
<br />
No requiere instalación ni conexión a internet.
<br /><br />
¿Qué hace?<br />
Genera una ruleta con distintas problemáticas ambientales<br />
Al detenerse, muestra un escenario<br />
Propone posibles acciones frente a esa situación<br />
El jugador debe escoger la respuesta correcta<br />
<br />
Tecnologías<br />
HTML<br />
CSS<br />
JavaScript (Canvas API)<br />
<br />
Notas<br />
Funciona completamente en el navegador<br />
No usa librerías externas<br />
Puede modificarse fácilmente agregando más opciones en el arreglo options dentro del código<br />
